Docs launch plan : ReadMe to Mintlify
Soft launch Mon 21 Sep. Launch Wed 23 Sep. Everything not listed here rolls out over the following month.

What has to be true on 23 Sep
1. New design and structure live at docs.northbeam.io.
2. No broken connections: app links, emails, Intercom and marketing all still land on a page.
3. Content can be updated and added through prompts and templates.
4. Permissions control who sees which sections.

Milestones

Tue 16 Sep : Kickoff : Ariella, Christine
Plan agreed. Asks sent to Mintlify: permissions setup, Slack agent, domain setup, Intercom setup, governance for employees and enterprise customers. Seats are done.

Wed 17 Sep : Content complete : Ariella
The 19 articles Tyler added to ReadMe since July are brought into the new site. Redirects added for the 13 old links the app uses that no longer have a page. Dan's team starts the domain setup so Monday's switch is one step.
Done when: every page in the old site and every link in the app has a destination on the new site.

Thu 18 Sep : Permissions and authoring working : Mintlify, Ariella, Tyler, Scott
Mintlify switches the site from fully locked to public, with only the Northbeam Internal section behind a login.
Tyler and Scott each add one article: one from a prompt in Slack, one from a template in the visual editor. Ariella records a short how-to video for both.
Test: logged out visitor sees the public site and not Internal; an employee logs in and sees Internal; both new articles are live in the right place. Covers criteria 3 and 4.

Fri 19 Sep : Connection tests and go or no-go : Ariella, Tyler, Dan
Automated check of all 178 old ReadMe links and all 101 links the app generates against the new site. Marketing links (website, HubSpot, decks, support macros) checked by hand.
NB AI plus Intercom test with Dan: a question with a docs answer returns a link that opens the right article on the new site; a question with no answer says it does not know and creates a ticket.
Go or no-go for soft launch, Christine by message. Covers criterion 2.

Mon 21 Sep : Soft launch : Dan, Ariella, Tyler
Dan points docs.northbeam.io at the new site. ReadMe stays running untouched as the backup.
Within the hour: rerun the link check against the live address, check the login on Internal, open an app help link, run the two NB AI questions again. CS and support told internally. Covers criterion 1.

Tue 22 Sep : Watch day : Ariella, Tyler
Watch for missing pages and support tickets, fix same day. Recheck NB AI links with Dan. Final go or no-go for the announcement by end of day.

Wed 23 Sep : Launch : Christine, marketing
Customer announcement. Marketing links updated where page names changed.

Backup and revert plan for 21 and 22 Sep
ReadMe is left exactly as it is, live and unchanged, until late October. A full export is saved before Monday.
If the new site is down or links are broadly broken and cannot be fixed within an hour: Dan points docs.northbeam.io back at ReadMe. It takes effect within 30 minutes. Nothing needs restoring because nothing on ReadMe was changed. Ariella tells CS and Mintlify, the cause is fixed on the new site, and the switch is retried.
Needed: Dan or a backup person available to make the switch on both days.
