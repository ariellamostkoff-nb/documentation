**Best for:** deciding which model to read before a budget or creative decision.

## Before you start

There is no single correct model — each answers a different question. Know what you're deciding before you pick.

## The steps

<Steps>
  <Step title="Understand the two families">
    Simple models give all credit to one touchpoint; multi-touch models divide it.
    [Attribution models →](/docs/attribution-models)
  </Step>
  <Step title="Compare models on your own data">
    Run the Model Comparison tool to see every model side by side.
    [Model Comparison tool →](/docs/what-is-northbeam-model-comparison-tool)
  </Step>
  <Step title="Set the window to match the decision">
    Short windows for fast feedback, long windows for considered purchases.
    [Attribution windows →](/docs/attribution-windows)
  </Step>
  <Step title="Walk one order through the models">
    See exactly how credit allocation changes what each model reports.
    [Credit allocation examples →](/docs/credit-allocation-examples)
  </Step>
</Steps>

## What to expect

Comparing against an ad platform? Remember most platforms report on last non-direct touch — pick the same model on both sides before drawing conclusions.
