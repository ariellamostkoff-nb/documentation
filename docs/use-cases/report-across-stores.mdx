**Best for:** brands running more than one storefront, region, or currency.

## The steps

<Steps>
  <Step title="Add each store or dashboard">
    Set up a dashboard per storefront or region.
    [Adding a store or dashboard →](/docs/adding-a-store-or-dashboard)
  </Step>
  <Step title="Configure multi-dashboard views">
    Use configurators to control what each dashboard shows.
    [Multi-dashboard setup with configurators →](/docs/multi-dashboard-setup-with-configurators)
  </Step>
  <Step title="Keep tracking consistent">
    Each storefront needs its own complete pixel and UTM setup.
    [Quickstart →](/docs/quickstart)
  </Step>
</Steps>

## What to expect

Per-store dashboards keep attribution clean; cross-store comparisons work when every store's tracking is equally complete.
