**Best for:** budget reviews that span search, social, email, and TV-style channels.

## Before you start

Different channel types produce different signals — a click-heavy channel and a view-heavy channel can't be read with the same glance.

## What to expect

The goal isn't identical metrics across channels — it's knowing which differences are measurement artifacts and which are real performance.
