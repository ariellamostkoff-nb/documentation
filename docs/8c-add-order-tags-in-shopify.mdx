## Create order tags

<Note>
  Note: Recharge customers don’t need to create order tags for subscriptions. You should still create order tags for other cases, like returns and exchanges.
</Note>

1. Log in to Shopify
2. From your Shopify Admin, click on ‘Orders’
3. Select an order
4. In the ‘Tags’ section, enter the name of the tag you want to add. If you enter the name of a new tag - it will automatically be created for future use across all orders.
5. Click save
6. Once you’ve created order tags, you can bulk update orders from the ‘Orders’ page
