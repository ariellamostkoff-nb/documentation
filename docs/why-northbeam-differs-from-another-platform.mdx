Different totals do not always mean data is missing. First confirm that both sources measure the same thing using the same settings.

## Match the comparison

Use the same:

1. **Date range and timezone**
2. **Metric definition**
3. **Filters and included accounts**
4. **Attribution model and window**
5. **Accounting mode**
6. **Data-generation time**

Then identify the metric that differs.

| Difference                        | Best next step                                                                                                                                                                                                                      |
| :-------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Visits or sessions                | [Visits Are Missing or Lower Than Expected](/docs/differences-in-visits)                                                                                                                                   |
| Ad spend or impressions           | [Spend or Impressions Are Missing](/docs/differences-in-ad-data)                                                                                                                                           |
| Shopify orders or revenue         | [Why Doesn't Northbeam Match My Shopify Reporting?](/docs/why-doesnt-northbeam-match-my-shopify-reporting)                                                                                                 |
| Attributed revenue or conversions | Review [Attribution Models](/docs/attribution-models), [Attribution Windows](/docs/attribution-windows), and [Accounting Modes](/docs/accounting-modes). |
| New versus returning customers    | Review [First-Time and Returning Data](/docs/new-vs-returning-data-1).                                                                                                                                     |
| Dashboard versus exported data    | [Dashboard and Export Data Don't Match](/docs/dashboard-and-export-data-dont-match)                                                                                                                        |

Ad platforms generally report using their own attribution rules. Northbeam applies the model, window, and accounting mode selected in Northbeam, so attributed results are not expected to match automatically.

If the underlying visits, orders, and spend are present, investigate reporting settings before treating the difference as a tracking failure.
