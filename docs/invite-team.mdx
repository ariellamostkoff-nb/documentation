## Frequently asked questions

<div className="nbt-qa">
  <div className="nbt-qa-q"><span className="nbt-def-num">01</span>Why should I invite account managers?</div>
  <div className="nbt-qa-a">Account managers are able to assist with onboarding tasks that you may be unable to complete on your own.</div>
</div>
<div className="nbt-qa">
  <div className="nbt-qa-q"><span className="nbt-def-num">02</span>Who should I invite?</div>
  <div className="nbt-qa-a">Any stakeholders interested in Northbeam data — ad buyers and managers, executives, and agency partners. If external partners run platform-specific advertising, collect login credentials from them or add them as account managers. An engineer can help implement the Northbeam pixel and the Orders API.</div>
</div>
<div className="nbt-qa">
  <div className="nbt-qa-q"><span className="nbt-def-num">03</span>What permissions do account managers have?</div>
  <div className="nbt-qa-a">They can add other managers, view all data, view and set connections, and perform every action the account owner can. Only the admin account manager can delete other account managers.</div>
</div>
<div className="nbt-qa">
  <div className="nbt-qa-q"><span className="nbt-def-num">04</span>What if the invitee doesn't receive an email?</div>
  <div className="nbt-qa-a">Check the spam folder. If it's still missing, they can generate a password through the password reset flow on [dashboard.northbeam.io](https://dashboard.northbeam.io).</div>
</div>
