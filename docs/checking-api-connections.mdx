## How to check your connections

1. Go to **Settings › Connections**.
2. Review each connected platform. A healthy connection shows a **Connected** status; a broken one shows an error or a **Reconnect** prompt.
3. For any platform showing an error, select it and follow the **Reconnect** flow to re-authorize.
4. Confirm each platform you advertise on is listed and connected. If a platform is missing, add it from this same page.
