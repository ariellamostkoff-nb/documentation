## Overview

We’re excited to announce that Northbeam has recently partnered with AppLovin to bring you a seamless integration! This partnership allows you to easily connect your AppLovin account to Northbeam, enabling AppLovin attribution.

# Step 3: Add Your Credentials in Northbeam

1. Go to **Settings > Connections** in your Northbeam dashboard.
2. Find the **AppLovin** section.
3. Enter your **Account ID** and **Report API Key**.

# Step 4: Add Northbeam UTMs

## Campaign-Level UTMs

AppLovin campaigns require Northbeam UTM parameters for proper attribution.

1. Click **Edit Campaign**
2. Click **Objective**
3. Scroll down to **Tracking Parameters**
4. Click **Edit**
5. Under **Measurement Partner Parameters**, select **Northbeam**
6. Click **Confirm**

## Creative-Level UTMs

<Warning>

  This is only required if a creative's Destination URL is set to **"Use another URL"**.
</Warning>

With this toggle, the creative will have its own URL and UTMs independent of the campaign and will not inherit campaign-level Northbeam UTMs. You must add Northbeam at the creative level.

1. Open the **Creative Set Settings**
2. Scroll to **Tracking Parameters**
3. Click **Edit**
4. Under **Measurement Partner Parameters**, select **Northbeam**
5. Click **Confirm**

# Step 5: Remove Custom Spend (Optional)

If you were previously uploading AppLovin spend into Northbeam using a custom spend sheet or API, you may need to adjust or remove these entries to avoid duplication after the integration is complete.

### Determine Whether to Adjust or Remove Spend

1. **Identify the Source of Custom Spend**:
   * Refer to [Step 1: Add Spend](/docs/add-spend) to review your custom spend sheet or API configuration.
   * Determine if the uploaded spend overlaps with the data now being pulled through the AppLovin integration.

2. **Adjust Spend if Needed**:
   * If there is overlap, adjust or remove the relevant entries from the custom spend sheet or API configuration to prevent double-counting.
   * If there is no overlap, you can leave the existing entries as they are.

<Warning>
  **Important**

  Duplicate spend entries in Northbeam may result in incorrect reporting and data discrepancies.
</Warning>

# AppLovin FAQ

## 1. Where is my data?

Your data should populate in Northbeam after the next data refresh. Typically, this occurs within 24 hours of completing the integration. If data is still missing, double-check that the Report API Key and Account ID were entered correctly.

## 2. What attribution models does the AppLovin integration support?

The AppLovin integration supports all attribution models available in Northbeam.

## 3. What should I do if my AppLovin data isn't appearing?

1. Verify that your AppLovin Report API Key and Account ID are correctly configured in **Settings > Connections**.
2. Ensure Northbeam UTM parameters have been added to your creatives — including any creatives using **"Use another URL"**, which require UTMs to be set at the creative level separately.
3. Check if your spend source was previously uploaded via a custom spend sheet or API. If so, make sure there is no duplication causing discrepancies. Refer to [Step 5: Remove Custom Spend](#step-5-remove-custom-spend-optional).

## 4. Why isn't my ad spend lining up?

Discrepancies in ad spend can often arise due to differences in **timezones** between Northbeam and AppLovin. By default, AppLovin reports data using **UTC**, whereas your Northbeam timezone is likely set to a different time zone, which you configured during onboarding.

To verify your Northbeam timezone:

1. Navigate to Settings > Profile in your Northbeam account.
2. Locate the Timezone field.
