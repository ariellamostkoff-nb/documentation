## TL;DR

**What is Model Comparison?**

* A tool that allows user to compare Northbeam attribution models (mainly [Clicks Only](/docs/attribution-models#clicks-only) vs. [Last Non-Direct Touch](/docs/attribution-models#last-touch-and-last-non-direct-touch)) to understand how revenue and transactions shift across models.

**Why is this important?**

* These differences will help you spot which campaigns are undervalued or overvalued by the platforms themselves, so you can shift your focus for better results.

**Here is an advanced tip:**

* Export data to CSV and overlay platform data (eg., Google Ads) to analyze differences more deeply in a spreadsheet.

Using our Model Comparison Tools allows you to uncover what's really driving performance with Northbeam's Clicks-Only attribution model. This tool provides an unbiased view of campaign effectiveness compared to other Last-Click models from in-platform reporting.
