# How do I track Influencer performance?

Our method for tracking influencers is the same way we [track all other alternative platforms](https://northbeam-customer-sucess.readme.io/docs/tracking-for-other-platforms).

You'll see we rely on Standard UTM Parameters (ex. source, medium, campaign) and a Custom Spendsheet.

We're currently working on a more robust influencer integration, although no ETA at this time.
