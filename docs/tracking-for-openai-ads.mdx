## Introduction

This guide will show you how to set up OpenAI Ads spend and click based attribution tracking in Northbeam.

Once the account is connected and the required Northbeam tracking parameter is added, Northbeam will receive:

* Spend data from OpenAI Ads
* Platform reported click data from OpenAI Ads
* Campaign, ad group, and ad identifiers used for reconciliation and attribution

OpenAI Ads supports the following Northbeam attribution models:

* Clicks Only
* Last Click
* First Click
* Linear

| Input                        | Output                                                                                                    | If the input is missing                                               |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| OpenAI Ads API key           | Northbeam can connect to the selected OpenAI Ads account and pull spend and platform reported click data. | OpenAI Ads data will not appear in Northbeam.                         |
| Northbeam tracking parameter | OpenAI Ads visits can be reconciled to the correct campaign, ad group, and ad.                            | Visits and attributed results may be missing or assigned incorrectly. |

## Before You Start

Make sure you have:

* Access to the correct OpenAI Ads account
* Permission to create an API key in OpenAI Ads Manager
* Access to the correct Northbeam dashboard
* Permission to edit the landing page query parameters for your OpenAI Ads ad groups

***

## Step 1: Create an OpenAI Ads API Key

1. Sign in to [OpenAI Ads Manager](https://ads.openai.com/).

2. Use the account switcher in the bottom left corner to select the ad account you want to connect.

3. Go to **Settings > General >API Keys**.

4. Click **Create New Key**.

   <Frame>
     <img src="/images/readme/9cb4cdf6-image.png" alt="" />
   </Frame>

5. Enter a recognisable name, such as `Northbeam ingestion`.

   <Frame>
     <img src="/images/readme/119f80dc-image.png" alt="" />
   </Frame>

6. Copy the API key.

<Note>
  > **Important: An API key is shown only once. Copy it when it is created. If it is lost, you must generate a new key.**
</Note>

Keep the API key secure. Do not include it in landing page URLs or share it outside the people responsible for the integration.

***

Open the OpenAI Ads integration in Northbeam:

* **During onboarding:** Go to **I**[**ntegrations and UTMs > OpenAI Ads**](https://dashboard.northbeam.io/onboarding?step=configure-platforms).

* **From the dashboard:** Go to [**Settings > Connections > OpenAI Ads**](https://dashboard.northbeam.io/settings/connections).

1. Paste the API key into the **API Key** field.
2. Confirm that the correct OpenAI Ads account is displayed.
3. Click **Connect**.

<Frame>

After the connection succeeds, the card will display the linked ad account and a green confirmation icon.

***

## Step 3: Add the Northbeam Tracking Parameter

Add the Northbeam tracking parameter to the **Landing page query parameters** field at the campaign level:

```text
nbt=nb:openai:openai:{campaign_id}:{ad_group_id}:{ad_id}
```

A campaign level parameter automatically applies to all ad groups and ads within that campaign. The template values are replaced with the relevant campaign, ad group, and ad IDs when the ad is served.

<Frame>
  <img src="/images/readme/6f6cf6ba-image.png" alt="" />
</Frame>

Repeat this process for each active campaign.

<Note>
  ### UTM Parameter Priority

  > **Important:** Parameters added at a lower level override those added at a higher level. The order of priority is **ad level > ad group level > campaign level**.
  >
  > If an ad group or ad already has its own query parameters, make sure the Northbeam `nbt` parameter is also included at that level. Otherwise, the campaign level parameter may be overridden and Northbeam tracking could be lost.
</Note>

## Step 4: Verify the Integration

Complete the following checks:

* The OpenAI Ads connection card shows a green confirmation icon.
* The correct ad account ID and timezone appear on the connection card.
* The NBT parameter is present in every active OpenAI Ads ad group.
* OpenAI Ads spend and platform reported clicks begin appearing in Northbeam.
* OpenAI Ads visits are assigned to the expected campaign, ad group, and ad.

The integration can backfill up to two years of historical spend when an account is first connected.

Historical attribution still depends on whether valid tracking parameters were present on the ads during that period.

## OpenAI Ads FAQ

## 1. Does the OpenAI Ads integration support attribution and revenue tracking?

Yes. OpenAI Ads supports click based attribution when the API connection is active and the required NBT parameter is present on the ad group.

## 2. Which Northbeam attribution models are supported?

OpenAI Ads supports:

* Clicks Only
* Last Click
* First Click
* Linear

Clicks + Modeled Views and Clicks + Deterministic Views are not supported for this integration.

## 3. Does OpenAI Ads require UTMs?

The required Northbeam tracking parameter is:

```text
nbt=nb:openai:openai:{campaign_id}:{ad_group_id}:{ad_id}
```

This parameter allows Northbeam to reconcile visits with the correct OpenAI Ads campaign, ad group, and ad.

## 4. Does Northbeam pull platform reported clicks?

Yes. Northbeam pulls platform reported click data from OpenAI Ads.

You can compare Northbeam visits with OpenAI Ads clicks to identify possible tracking coverage issues.

## 5. How far does spend backfill?

The integration can backfill up to two years of historical spend when the account is first connected.

## 6. What should I do if I lose the API key?

OpenAI Ads displays an API key only once.

If you lose it, return to **Settings > API Keys**, generate a new key, and update the OpenAI Ads connection in Northbeam.

## 7. Why is OpenAI Ads data missing or incomplete?

Check the following:

* Go to **Settings > Connections** and confirm that the OpenAI Ads connection is green.
* Confirm that the correct OpenAI Ads account is linked.
* Generate a new API key and reconnect if the existing key is no longer valid.
* Confirm that every active ad group contains the exact Northbeam tracking parameter.
* Check that the landing page preserves the NBT parameter after redirects.
