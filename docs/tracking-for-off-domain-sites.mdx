## What Is an Off-Domain Site?

An **off-domain site** is a webpage hosted on a different root domain from the website connected to Northbeam.

### Common Examples

* Blog articles or editorial reviews
* “Top 10” product roundups
* Sponsored content or advertorials
* Affiliate or partner landing pages
* Third-party presell pages

### Example Domains

* **Off-Domain Site:** `https://www.mysubscriptionaddiction.com/northbeam`
* **Main Domain:** `https://www.northbeam.io`

The **main domain** is the website connected to Northbeam and where the Northbeam Pixel is installed.

### Example Flow

**Meta Ad →&#x20;**`mysubscriptionaddiction.com`**&#x20;→&#x20;**`northbeam.io`

Without the correct setup, Northbeam may record the visit as a referral from `mysubscriptionaddiction.com` instead of connecting it to the original Meta ad.

> **Tracking requirement:** The Northbeam Pixel must fire on the main domain while the correct Northbeam tracking parameters are available.

***

## Why Standard Tracking Does Not Work

Northbeam’s first-party tracking is tied to your main root domain.

When an ad sends someone directly to an off-domain site, the visitor is landing on a different root domain where Northbeam does not have first-party tracking.

When the visitor later moves from the off-domain site to the main domain, the browser treats this as a new session from a third-party referral. The original ad session does not automatically carry across the two domains.

As a result, Northbeam cannot connect the initial ad click on the off-domain site to the later visit on the main domain unless the original Northbeam tracking information is preserved.

Without the correct setup, the visit may only appear as a referral from the off-domain site and will not be connected to the original:

* Campaign
* Ad set
* Ad
* Associated ad spend

Northbeam supports two ways to address this:

1. **Use a Northbeam Redirect Link**
2. **Preserve the Northbeam tracking parameters between domains**

***

## Option 1: Redirect Links

**Available for:** Meta, Pinterest, Klaviyo, and Attentive

This is the preferred option when available.

### How It Works

A Redirect Link briefly routes the visitor through the main domain before sending them to the off-domain site.

### Example Flow

**Meta Ad →&#x20;**`northbeam.io`**&#x20;redirect →&#x20;**`mysubscriptionaddiction.com`**&#x20;→&#x20;**`northbeam.io`

This brief stop on the main domain allows the Northbeam Pixel to fire and capture the original ad information as a first-party event.

### Benefits

* Captures the original ad information before the visitor reaches the off-domain site
* Does not require the Northbeam Pixel to be installed on the off-domain site
* Requires less custom development than preserving parameters across multiple pages

### Limitations

* Google Ads and X may block or penalize redirect behavior
* Redirect Links are only available for supported platforms
* Traffic from unsupported platforms, such as TikTok or Taboola, cannot use this method

### Setup Steps

1. Open the **Mini Menu** in Northbeam.
2. Select **Guides → Redirect URLs Guide**.
3. Enter the final off-domain destination URL.
4. Generate the Redirect Link.
5. Copy the generated URL and tracking parameters into the ad platform.

## Option 2: Preserve Tracking Parameters Between Domains

**Available for:** All platforms

Use this option when Redirect Links are unavailable, including for platforms such as TikTok and Google Ads.

This option allows the visitor to land directly on the off-domain site, as long as the original Northbeam tracking parameters are preserved when the visitor moves to the main domain.

This is a more technical setup and will usually require help from your development team.

### How It Works

The ad sends the visitor to the off-domain site with Northbeam’s required tracking parameters.

When the visitor later moves to the main domain, the same parameters and IDs must still be present in the URL.

### Required Flow

**Ad with Northbeam parameters → Off-Domain Site → Main Domain with the same Northbeam parameters**

When the visitor reaches the main domain:

* The Northbeam Pixel must fire
* The full Northbeam parameter string must still be present
* The original campaign, ad group or ad set, and ad IDs must be preserved
* The pixel must be able to read those parameters

***

### TikTok Example

Northbeam’s standard TikTok parameters are:

```text
nbt=nb:tiktok::__CAMPAIGN_ID__:__AID__:__CID__&nb_platform=tiktok
```

For example, an ad might send traffic to the off-domain site with IDs like:

```text
https://www.mysubscriptionaddiction.com/article?nbt=nb:tiktok::123456789:987654321:456789123&nb_platform=tiktok
```

When the visitor clicks through to the main domain, those same values must be preserved:

```text
https://www.northbeam.io/product?nbt=nb:tiktok::123456789:987654321:456789123&nb_platform=tiktok
```

In this example:

* `123456789` is the campaign ID
* `987654321` is the ad group ID
* `456789123` is the ad ID

***

### Google Ads Example

Northbeam’s standard Google Ads parameter is:

```text
nbt=nb%3Aadwords%3A{network}%3A{campaignid}%3A{adgroupid}%3A{creative}
```

For example, an ad might send traffic to the off-domain site with dummy values like:

```text
https://www.mysubscriptionaddiction.com/article?nbt=nb%3Aadwords%3Ag%3A123456789%3A987654321%3A456789123
```

When the visitor clicks through to the main domain, that same value must be preserved:

```text
https://www.northbeam.io/product?nbt=nb%3Aadwords%3Ag%3A123456789%3A987654321%3A456789123
```

In this example:

* `g` is the Google network value
* `123456789` is the campaign ID
* `987654321` is the ad group ID
* `456789123` is the creative ID

> These are dummy IDs used only to show the expected URL structure.

***

### Important Technical Considerations

The parameters can be lost while the visitor navigates the off-domain site.

For example, a visitor may:

1. Land on an article on the off-domain site.
2. Navigate to another page on the off-domain site.
3. Click a button leading to the main domain.

If the original parameters are not stored and preserved, they may disappear before the visitor reaches the main domain.

Your team is responsible for ensuring that the original Northbeam parameters are retained and added to the final link leading to the main domain.

This may require:

* Custom development
* Scripts
* Cookies
* Local storage
* Link rewriting
* Another method chosen by your development team

Northbeam cannot provide specific implementation instructions because every website and navigation flow is different.

> **The goal:** The visitor must reach the main domain with the original Northbeam tracking string and IDs still present when the Northbeam Pixel fires.

***

## Which Option Should I Use?

Use **Redirect Links** when:

* The ad platform supports them
* You want the simpler and preferred setup
* You cannot control the code or links on the off-domain site

Use **parameter preservation** when:

* Redirect Links are not supported
* You control the off-domain site or can work with its development team
* Your team can reliably preserve the parameters throughout the full journey

***

## How Do I Confirm the Setup Is Working?

Test the complete journey using a live ad URL or a test URL containing the required Northbeam parameters.

Confirm that:

1. The visitor reaches the main domain.
2. The Northbeam Pixel fires on the main domain.
3. The correct Northbeam parameters are still present when the pixel fires.
4. Northbeam records a Visit under the expected campaign, ad set, and ad.

Check **Visit data** in Northbeam.

If Visits appear under the correct campaign, ad set, and ad, the setup is working.

Northbeam uses Visits to confirm tracking, not platform-reported clicks or conversions.

***

## Can I Add Basic UTMs to the Link From the Off-Domain Site to the Main Domain?

You can add standard UTMs to the link from the off-domain site to the main domain, but this will not necessarily connect the visit to the original ad.

Basic UTMs may help Northbeam categorize the traffic, but they may not contain the campaign, ad set, ad, and other IDs needed to connect the visit to the original ad spend.

For paid advertising, use either:

* A Northbeam Redirect Link
* The complete set of required Northbeam tracking parameters preserved between the off-domain site and the main domain
