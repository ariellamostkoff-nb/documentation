</Note>

Once connected, Claude can use your Northbeam access to answer questions about performance, attribution, spend, orders, and dashboards. The connection is read-only. Claude can query and summarize your Northbeam data, but it cannot make changes in Northbeam.

The setup steps differ between Claude connectors and Claude Code, but the overall flow is the same:

1. Connect Northbeam to Claude.
2. Sign in with your Northbeam account.
3. Verify that Claude can access your dashboards.

# Before you start

You will need:

1. A Northbeam account you can sign in to.
2. Access to Claude custom connectors or Claude Code. Custom connectors using remote MCP are available in **Claude** and **Claude Desktop** across **Free, Pro, Max, Team, and Enterprise** plans.
3. The Northbeam MCP server URL: `https://mcp.northbeam.io`.

# If you’re on Team or Enterprise

If your Claude access is managed by your organization, an Owner or Primary Owner may need to add the Northbeam connector first. After that, each user enables the connector and signs in individually.

If you’re on an individual plan, you can set up Northbeam yourself.

<br />

***

# Individual setup

Use these steps if you are on an individual Claude plan and can add your own custom connectors.

### Claude on the web (`claude.ai`) or Claude Desktop

1. Open **Claude** and go to **Customize → Connectors**.
2. Click the **+** button next to **Connectors**.
3. Enter:
   * **Name:** `Northbeam`
   * **URL:** `https://mcp.northbeam.io`
   * **Advanced settings**: leave blank
4. Click **Add**.
5. When prompted, sign in with your normal Northbeam login.
6. Finish the connection flow. Once complete, the connector should show as connected.
7. (Optional) Choose **Always allow** for read-only tools.

### Claude Code

1. Run this command in your terminal:
   ```text
   claude mcp add --scope user --transport http Northbeam https://mcp.northbeam.io
   ```
2. Open Claude Code.
3. Run `/mcp`.
4. Select Northbeam.
5. Choose Authenticate.
6. Complete the browser sign-in flow with your normal Northbeam login.

If you see `Failed to connect` immediately after adding the server, that is expected. The connection becomes active after you complete authentication.

## Verify the connection

Start a new chat and ask Claude:

> Use Northbeam to list my dashboards.

If Claude returns your dashboards, the connection is working.

# Team / Enterprise setup

If you are on a Claude Team or Enterprise plan, setup happens in **two parts**:

1. A plan **Owner/Admin** adds the connector for the organization.
2. Each user enables the connector and signs in with their own Northbeam account.

## Part 1: Admin setup

An organization **Owner** or **Admin** should:

1. Open Claude organization settings.
2. Go to **Organization settings → Connectors**.
3. Add a custom connector.
4. Enter:
   * **Name:** `Northbeam`
   * **URL:** `https://mcp.northbeam.io`
5. Save the connector.

After that, the connector becomes available to members of the organization, but it is **not connected for them automatically**.

## Part 2: Individual user setup

Once your admin has added Northbeam for the organization, you can connect your Northbeam login to Claude.

### Claude on the web (`claude.ai`) or Claude Desktop

1. Open **Claude** or **Claude Desktop**.
2. Go to your **Connectors** settings.
3. Find **Northbeam** in the available connectors list and click **Connect**.
4. Sign in with **your own** Northbeam login.
5. Finish authentication.

Each user must authenticate individually. Adding the connector at the org level only makes it available; it does not grant access by itself.

### Claude Code

1. Open Claude Code.
2. Run `/mcp`.
3. Select `claude.ai Northbeam` from the list. You may need to scroll down to see it.
4. Choose Authenticate.
5. Complete the browser sign-in flow with your normal Northbeam login.

## Verify the connection

Start a new chat and ask Claude:

> Use Northbeam to list my dashboards.

If Claude returns your dashboards, you are connected.

# What you can ask Claude

Once connected, Claude can pull live data from your Northbeam dashboards. Example prompts:

1. `List my Northbeam dashboards.`
2. `What was my Meta ROAS last week vs the prior week?`
3. `Show me my top 10 orders by revenue this month.`
4. `Break down spend and revenue by platform for the last 30 days.`

If you have access to more than one dashboard, tell Claude which one to use so it queries the right account.
