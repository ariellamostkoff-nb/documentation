---
title: "Changing Currency"
description: "By default, we convert all currencies to US Dollars (USD) using the daily exchange rate."
---

# How do I change my currency?

Please submit an inquiry [here](https://www.northbeam.io/submit-a-support-ticket) and indicate which currency you'd like to change to.

# Can I easily toggle between two currencies?

Currency change is a manual process in our backend. Once it's been deployed, all numbers in your dashboard are converted. The only way to revert is to submit another request to our team.

# Are platform metrics converted too?

Yes, all Northbeam-reported and Platform-reported metrics will be converted to the client’s currency of choice.

If needed, there is an option to convert Northbeam-reported metrics, but not convert platform metrics. If this applies to you, please indicate it in your inquiry.

# How does this feature work with Custom Spendsheets?

For Custom Spendsheets, please insert spend in USD. It will be converted to your requested currency before populating in your dashboard.

# Does this feature have support in the Mobile App?

This is something our team is still working on. If this is requested, please submit an inquiry [here](https://www.northbeam.io/submit-a-support-ticket).
