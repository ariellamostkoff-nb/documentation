Ad platforms change: APIs go down, integrations break, and platforms
sometimes redefine what their data means. When that happens, it shows up
in your numbers — this log records it.

<Update label="2026-08" description="Channel changelog introduced">
  This log starts now. Going forward, platform-side incidents, integration
  changes, and data-definition changes will be recorded here per channel,
  with dates — so when a number moves, you can check whether the channel
  itself changed first.
</Update>

<Info>
  A number moved and there's no entry here? Run
  [Diagnose a ROAS drop](/docs/use-cases/diagnose-a-roas-drop) — most
  differences are measurement, not outages.
</Info>
