<Note>
  Please Note

  **Ensure your UTM starts with “&” or “?”.**

  * If you have existing parameters, use “&”:
  * Ex: northbeam.io?utm\_source=tradedesk\*\*\&nb\_platform=tradedesk…\*\*
  * If you do not have existing parameters, use “?”:
  * Ex: northbeam.io\_**?nb\_platform=tradedesk…**
</Note>
