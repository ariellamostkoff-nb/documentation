## Step 2: Insert Northbeam UTM Parameters


Please add **two custom UTM parameters** in the **Build URL parameters** menu for all new and existing ads:

| Parameter Name | Value                                        |
| :------------- | :------------------------------------------- |
| `nbt`          | `nb:tiktok::__CAMPAIGN_ID__:__AID__:__CID__` |
| `nb_platform`  | `tiktok`                                     |

1. In your Ad settings, click **Build URL parametersr**
2. Click **Add parameter** twice and all the two custom parameters listed above.
3. Click **Apply**.
