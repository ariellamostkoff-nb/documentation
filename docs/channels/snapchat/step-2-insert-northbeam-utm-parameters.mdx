There are two ways to insert UTMs. Either way works just fine:

1. Appending them in the URL
2. Using the Custom Parameter field

## Method 1: Appending in the URL

Insert the following UTM at the end of your URL:

```
?nbt=nb:snapchat:{{site_source_name}}:{{campaign.id}}:{{adSet.id}}:{{ad.id}}
```

#### Have existing UTM parameters?

If have existing UTMs, add ours to the end and use an ampersand (&) to connect your existing parameters to our parameters.

Example: utm\_source=paid\&utm\_mediun=snapchat\*\*\&nbt=nb:snapchat:\{\{site\_source\_name}}:\{\{campaign.id}}:\{\{adSet.id}}:\{\{ad.id}}\*\*

## Method 2: Using the Custom Parameter field

Please create a **custom parameter** with the following name and value:

**Parameter Name:** nbt

**Parameter Value:** nb:snapchat:\{\{site\_source\_name}}:\{\{campaign.id}}:\{\{adSet.id}}:\{\{ad.id}}
