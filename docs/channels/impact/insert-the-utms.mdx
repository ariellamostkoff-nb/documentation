## Step 2: Insert Northbeam UTM Parameters


Add the following custom UTM parameter to the click URLs for all new and existing Impact ads:

| Parameter Name | Value                                 |
| :------------- | :------------------------------------ |
| `nbt`          | `nb:impact::{ircid}:{irpid}:{iradid}` |

### Step-By-Step Guide

1. In Impact, go to **\[User profile] → Settings → Gateway**

<Frame>
  <img src="https://files.readme.io/870aeeb366f2c80f2525ba729985349eea31eacd5cd672b384c52e6c0512121c-CleanShot_2026-05-04_at_16.33.10.png" alt="" />
</Frame>

2. Under **Program Tracking Template**, add a new parameter row:
   1. **Name:** `nbt`
   2. **Value:** `nb:impact::{ircid}:{irpid}:{iradid}`

<Frame>
  <img src="https://files.readme.io/2f25738228dbafdf77fe6e05aef9b6de200452c30c900a56418d2d2db2de3259-CleanShot_2026-05-04_at_16.38.10.png" alt="" />
</Frame>

3. Click **Save**
