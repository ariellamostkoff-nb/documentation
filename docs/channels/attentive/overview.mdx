| :------------------------------- | :-------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- |

## Step 5: Implement Sign Up Event


Once the integration is set up, we'll begin pulling the raw sign up events from your Attentive account. In order to see attribution of these events (ex. Facebook Ads drove X sign ups), we'll need our Email Sign Up Event or Custom Goal Event script to be placed.

Please choose one:

| Type                                                                            | Details                                                               |
| :------------------------------------------------------------------------------ | :-------------------------------------------------------------------- |
| [Sign Up Event- Email](/docs/setting-up-klaviyo-for-northbeam) | Events are reported under the default metric called "Email Sign Up"   |
| [Custom Goal Event](/docs/setting-up-custom-goals)     | Events are reported under a custom metric called anything you'd like. |
