Every channel setup follows the same three steps:

<Steps>
  <Step title="Connect the account">
    Link the platform to Northbeam so spend and campaign structure sync.
  </Step>
  <Step title="Insert the UTMs">
    Add Northbeam parameters to your ads so visits attribute back to them.
  </Step>
  <Step title="Confirm tracking">
    Verify UTMs are captured and the connection is syncing.
  </Step>
</Steps>

Some channels add an FAQ for platform-specific questions.
