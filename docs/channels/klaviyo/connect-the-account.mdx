## Step 1: Connect Your Klaviyo Account


### What does the connection do?

Our integration with Klaviyo imports all Klaviyo events associated with the  "new subscriber" tag. You'll see these reporting under the metric called "Email Sign Ups".

### 1A: Find your Public API Key

1. Log in to Klaviyo.
2. Go to **Settings** → **API Keys**.
3. Copy the **Public API Key**

<Frame>
  <img src="/images/readme/268a6a64-mceclip0.png" alt="" />
</Frame>

### 1B: Find your Private API Key

1. In Klaviyo, go to **Settings** → **API Keys**.
2. Under **Private API Keys**, click **Create Private API Key**.
3. Name the key something like **Northbeam (Read-only)**.
4. Set permissions to **Read-only**.
5. Click **Create**.

### 1C: Enter API Keys in Northbeam

In Northbeam, paste your **Public API Key** and **Private API Key** to complete the Klaviyo connection..
