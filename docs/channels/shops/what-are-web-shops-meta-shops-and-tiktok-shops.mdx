We report conversions from three different types of **Shops**.  Each Shop corresponds to a specific checkout experience, or **where** your customer places their order.

| Shop Type    | Description                               |
| :----------- | :---------------------------------------- |
| Web Shops    | Orders placed through your Web Storefront |
| Meta Shops   | Orders placed through Meta Shops          |
| TikTok Shops | Orders placed through TikTok Shops        |

## Web Shops

This is your store's normal checkout experience, where our [Purchase Event](/docs/add-pixel) fires.

## Meta Shops

This is Facebook's (and Instagram's) native shopping experience -- where customers purchase directly from the platform, as opposed to your online store. [Learn about Meta Shops here](https://www.facebook.com/business/shops).

## TikTok Shops

This is TikTok's native shopping experience -- where customers purchase directly from TikTok's platform, as opposed to your online store. [Learn more about TikTok Shops here](https://shop.tiktok.com/business/us).

<Warning>
  Meta Shops and TikTok Shops attribution are only supported using the Clicks Only or the Clicks + Modeled Views attribution models.

  If using First Touch, Last Touch, Last Non-Direct Touch, or Linear -- Meta and TikTok Shops will report as its own line item. You'll simply see total orders and revenue from these channels.
</Warning>
