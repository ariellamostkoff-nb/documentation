## Northbeam 3.0: The New Northbeam Experience

Northbeam 3.0 is the next generation of the Northbeam analytics platform. It delivers significantly faster performance, a cleaner interface, and expanded analytical capabilities. Everything you rely on from Northbeam 1.0 is still available, now rebuilt for clarity, depth, and speed.

***

### Key Improvements in Northbeam 3.0

#### Faster Performance

Northbeam 3.0 is roughly twice as fast as 1.0 across dashboards, graphs, filters, and table interactions.<br />The entire experience is more responsive, making daily analysis smoother and more efficient.

#### Easier to Use

Northbeam 3.0 introduces a redesigned interface that improves clarity and reduces interpretation effort.

**Usability upgrades include:**

* Tooltips embedded directly inside tables for Touchpoints, Revenue, ROAS, CAC, Visitors, and Customers
* First and returning customer splits shown consistently for context
* Clearer definitions for accrual vs cash reporting
* One click to switch between Northbeam 1.0 and Northbeam 3.0
* Streamlined table layouts, more intuitive navigation, and cleaner visual hierarchy

#### More Powerful Analysis

Northbeam 3.0 expands the number of metrics you can track and adds new ways to understand customer journeys and channel influence.

**Major upgrades:**

* The Touchpoints column now displays the most common customer journey for any selected breakdown (Clicks Only model)
* The Sales page now includes:
  * Customer metrics (All, New, Returning)
  * Visitor metrics
  * CAC (New), CPV, RPV, AOV
  * Upgraded visualizations, including split and stacked line charts
  * Full screen mode for tables and graphs
  * One click access to Metrics Explorer
* The Orders page now includes:
  * Order-level journey details showing how each touchpoint received credit
  * Filters to isolate orders where specific platforms receive credit under selected models, modes, or lookback windows
  * Quickfilters for common investigative patterns

### Metric Definitions

Clear reference definitions for all core and expanded metrics in Northbeam 3.0.

#### New Metrics

**RPV (All)**<br />Revenue per visitor.

**RPV (New)**<br />New revenue per new visitor.

**RPV (Returning)**<br />Returning revenue per returning visitor.

**Customers (All)**<br />Total unique customers in the reporting window.

**Customers (New)**<br />Customers making their first purchase in the reporting window.

**Customers (Returning)**<br />Customers who have purchased before the reporting window.

**Customers (Returning, Active)**<br />Returning customers who purchased within the last 60 days.

**Customers (Returning, Reactivated)**<br />Returning customers who have not purchased in the last 60 days.

**Touchpoints (Attributed, All / New / Returning)**<br />Average number of touchpoints that received attribution credit for all, new, or returning orders.

**Visitors (All / New / Returning)**<br />Unique visitors segmented by new vs returning behavior.

**Applovin conversion metrics**<br />Reported conversion metrics from Applovin.

**Vibe conversion metrics**<br />Reported conversion metrics from Vibe.

<br />

#### Updated Metrics (new naming, same definition)

**CAC → CPO**<br />Customer acquisition cost is now cost per order. Previously, CAC was functionally measuring CPO, so the new name aligns with the actual definition.

**eCPNV → CPV**<br />Previously only applied to new visits. CPV now applies to both new and returning visitors.

**Transactions → Orders**<br />Updated to align with standard naming.
