Onboarding takes you from a new account to data flowing: set up your
account, install tracking, add orders, add spend.

* **Fastest path:** the [Quickstart](/docs/quickstart) — the five steps, end to end
* **What done looks like:** pixel firing, orders and spend syncing, channels connected
* **Timeline:** see [What to expect during implementation](/docs/what-to-expect-during-implementation)

Work the groups in this section top to bottom — the order is the method.
When you reach channels, continue in [Channels & stores](/docs/integrations-and-utms).
