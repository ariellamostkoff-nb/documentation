Use cases start from the outcome you want and link into the full
guides. Every article follows the same shape:

**Best for → Before you start → The steps → What to expect → Related**

Three groups:

* **Diagnose & reconcile** — when numbers moved or don't match
* **Decide & optimize** — choosing models, comparing channels, testing lift
* **Operate & report** — the recurring work: reporting, exports, integrations

If a number just moved and you're in a hurry:
[Diagnose a ROAS drop](/docs/use-cases/diagnose-a-roas-drop).
